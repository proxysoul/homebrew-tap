# ProxySoul Homebrew Tap

Homebrew packages for [Empryo](https://empryo.com) and SoulForge.

## Empryo

Terminal app (macOS and Linux):

```bash
brew install proxysoul/tap/empryo
```

Desktop app (macOS 13 or later):

```bash
brew install --cask proxysoul/tap/empryo-desktop
```

Update with `brew upgrade`. The desktop app also updates itself.

## SoulForge

```bash
brew install proxysoul/tap/soulforge
```
